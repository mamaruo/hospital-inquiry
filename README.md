# 技术栈
前端：
Vue.js + TypeScript
UI 组件：shadcn-vue
状态管理：Pinia
路由：Vue Router
实时通信：WebSocket
样式：Tailwind CSS

后端：
Spring Boot
认证：Spring Security with JWT
ORM：Spring JPA
数据库：PostgreSQL
实时通信：WebSocket

# 功能
患者端：注册登录、问诊人管理、三步发起问诊、实时文字/图片聊天、医生检索
医生端：待接诊、接诊、进行中问诊、实时聊天、结束问诊
管理端：科室管理、患者管理、医生创建/编辑/重置密码
通用：个人中心、修改密码、忘记密码（手机号+身份证验证）、JWT 登录、角色路由守卫
